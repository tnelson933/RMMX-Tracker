---
name: Dashboard product scope
description: Owner's scope rule for account overview versus event check-in metrics.
---

The dashboard is an overall view of the account. Check-in is per event and does
not belong as an account-wide summary metric.

**Why:** The owner stated, “checked in is per event. the dashboard is an overall
view of the account.”

**How to apply:** Keep event check-in metrics on event-specific screens. Do not
reintroduce a total-checked-in card to the account dashboard.
